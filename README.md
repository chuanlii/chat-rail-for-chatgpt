# ChatRail

给 ChatGPT 网页版的长对话加一条「导航轨道」。

在对话正文左侧有一条极细的轨道，**一条短横线 = 一次提问**：

- **悬停**横线 → 浮层显示那一次提问的内容
- **点击**横线 → 直接跳到那一次提问，落点对齐到阅读线并闪一下
- 轨道**底部那条橙色横线** → 一键跳到最后一轮回答的结尾（长回答从头读到一半、想回底部继续问时用）
- 滚动时当前所在的提问会加长加粗，随时知道自己在哪一轮

轮次很多时行距自动压缩，整列始终留在轨道内，不会溢出；深浅色主题自适应。

## 安装

Chrome / Edge 手动加载（未上架应用商店）：

1. 下载本仓库：`Code` → `Download ZIP`，或者
   ```
   git clone https://github.com/chuanlii/chat-rail-for-chatgpt.git
   ```
   解压到任意目录（路径不要删，扩展会一直从这个目录加载）
2. 打开 `chrome://extensions`（Edge 用 `edge://extensions`）
3. 打开右上角的「开发者模式」
4. 点「加载已解压的扩展程序」，选中**包含 `manifest.json` 的那一层目录**（也就是本仓库根目录）
5. 打开 <https://chatgpt.com> 里任意一段对话并刷新页面，左侧出现横线轨道就装好了

装好后：`Ctrl` + `Shift` + `Y` 显示 / 隐藏轨道；点工具栏里的 ChatRail 图标，可以在弹窗里调整轨道位置、浮层方向和距正文的距离。
